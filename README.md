# 손그림 뮤직비디오 스킬 (GPT Codex용)

Suno에서 만든 노래 + 가사만 넣으면, Codex가 영상 생성 AI 없이
"연필이 그려나가는" 화이트보드 애니메이션 뮤직비디오(mp4)를 만들어 주는 프로젝트 템플릿입니다.
(9/14 챗사피엔스 특강에서 한정은희 강사님이 보여준 방식과 같은 파이프라인)

## 준비물

1. **ChatGPT Plus 구독** (월 $20) — Codex 사용 조건
2. **Codex 설치** — 아래 중 편한 것 하나
   - VS Code 확장: 확장 마켓에서 "Codex – OpenAI's coding agent" 설치 후 ChatGPT 계정 로그인
   - 터미널(CLI): `npm install -g @openai/codex` 설치 후 `codex` 실행
3. **노래 파일**(mp3)과 **가사**(txt) — Suno에서 다운로드

## 사용법 (3단계)

### 1. 파일 넣기

```
codex-손그림뮤비-스킬/
├── AGENTS.md          ← Codex가 자동으로 읽는 스킬 본체 (수정 불필요)
├── input/
│   ├── song.mp3       ← 여기에 노래
│   ├── lyrics.txt     ← 여기에 가사 (한 줄 = 한 소절)
│   └── images/        ← (선택) 직접 만든 장면 이미지
└── output/            ← 결과물이 여기 생김
```

### 2. Codex를 이 폴더에서 열기

- VS Code: 이 폴더를 열고 Codex 패널 실행
- CLI: 터미널에서 `cd` 로 이 폴더에 들어간 뒤 `codex` 실행

### 3. 지시하기

PROMPTS.md에 있는 시작 프롬프트를 복사해 붙여넣으면 됩니다. 가장 짧게는:

> input 폴더에 노래와 가사 넣었어. AGENTS.md대로 손그림 뮤직비디오 만들어줘. 스타일은 미니멀 스케치로.

Codex가 장면을 나누고, (이미지가 없으면) 장면별 이미지 프롬프트를 주면서
ChatGPT에서 생성해 넣어 달라고 할 겁니다. 이후 프리뷰(preview.html) → 확인 → 최종 mp4 순서로 진행됩니다.

## 스타일 3종

| 스타일 | 느낌 | 어울리는 곡 |
|---|---|---|
| `pencil` | 흑백 연필화 + 크로스해칭 | 록, 힙합, 강한 곡 |
| `sketch` | 여백 많은 스케치 + 연한 수채 | 발라드, 잔잔한 곡 |
| `photo` | 시네마틱 실사 (위→아래 리빌) | 웅장한 곡, 서사극 |

같은 프로젝트에서 "실사 버전으로도 만들어줘"라고 하면 타이밍·자막은 그대로 두고
이미지만 갈아끼워 v2를 만들어 줍니다 (기존 버전 보존).

## 자주 막히는 곳

- **ffmpeg 없다고 나올 때**: Windows는 터미널에서 `winget install Gyan.FFmpeg` 실행 후 터미널 재시작
- **이미지가 그림체가 제각각일 때**: 장면 프롬프트 앞에 같은 스타일 문구를 붙였는지 확인 (AGENTS.md의 스타일 일관성 규칙)
- **연필 선이 정신없을 때**: "선 밀도 낮추고 여백 많게 다시"라고 지시 — sketch 스타일로 바꾸는 것도 방법
- **가사 타이밍이 안 맞을 때**: `input/timings.txt`에 `0:15 첫 소절 가사…` 식으로 몇 줄만 적어줘도 훨씬 정확해짐
